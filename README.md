# ЛР1. Интеллектуальная классификация объектов ИС (ML-классификация)

Дисциплина «Проектирование и интеграция информационных и интеллектуальных систем», ЛГТУ.
Выполнил: Морозов А. А., группа М-РИТ-25-1.

**InvestNews** — информационная система инвестора: лента новостей по ценным бумагам портфеля.
Тональность каждой новости (негативная / нейтральная / позитивная) определяет отдельный
ML-сервис. ИС сохраняет результат в БД и использует его в прикладной логике:
уверенный негатив по бумаге из портфеля помечается как «Требует внимания».

```
Браузер ──HTTP──> Django (ИС, порт 8000) ──REST/JSON──> ML-сервис FastAPI (порт 8001)
                        │                                     │
                     SQLite                       модель TF-IDF + LogisticRegression
```

## Состав

| Каталог | Назначение |
|---|---|
| `data/all-data.csv` | датасет [Sentiment Analysis for Financial News](https://www.kaggle.com/datasets/ankurzing/sentiment-analysis-for-financial-news) (FinancialPhraseBank, CC BY-NC-SA 4.0), 4846 заголовков |
| `data/demo_news.csv` | 27 новостей, отложенных для демонстрации (в обучении не участвуют) |
| `ml/train.py` | подготовка выборки, обучение и сравнение моделей, сохранение лучшей |
| `ml/features.py` | признаки: нормализация текста для TF-IDF, эмбеддинги (усреднённые векторы GloVe из spaCy) |
| `ml/models/` | обученная модель (`sentiment_model.joblib`) и её метаданные |
| `ml/reports/` | метрики, матрицы ошибок, распределение классов |
| `ml_service/` | ML-сервис на FastAPI: `GET /health`, `POST /predict` |
| `webapp/` | ИС на Django: модели БД, веб-интерфейс, клиент ML-сервиса, бизнес-правила |

## Результаты обучения (тестовая выборка, 962 новости)

| Модель | Accuracy | Macro-F1 |
|---|---|---|
| Базовая (самый частый класс) | 0,595 | 0,249 |
| TF-IDF + логистическая регрессия (**выбрана**) | **0,809** | **0,770** |
| Эмбеддинги GloVe + логистическая регрессия | 0,647 | 0,598 |
| TF-IDF + эмбеддинги + логистическая регрессия | 0,736 | 0,687 |

## Запуск (Windows)

```bat
setup.bat              :: venv + зависимости + миграции
run_ml_service.bat     :: окно 1: ML-сервис, http://127.0.0.1:8001/docs
run_webapp.bat         :: окно 2: ИС, http://127.0.0.1:8000/
.venv\Scripts\python webapp\manage.py seed_demo   :: демо-данные (бумаги, аналитики, 27 новостей)
```

Демо-учётная запись администратора (только для локального запуска): `admin` / `admin12345`.

Переобучение модели: `pip install -r requirements-train.txt`, затем `python -m ml.train`.

Тесты: `python -m pytest ml_service` и `python webapp\manage.py test news`.

## API ML-сервиса

```http

200 OK
{"label": "positive", "label_ru": "позитивная", "confidence": 0.9858,
```

Если ML-сервис недоступен, ИС сохраняет новость без тональности. Её можно классифицировать
позже кнопкой «Классифицировать новости без тональности».
